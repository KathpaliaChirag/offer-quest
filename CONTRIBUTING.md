# Contributing to Offer Quest 🤝

Thank you for helping somebody else walk into an OA or interview a little more prepared.

## What belongs here

- Publicly available OA questions, patterns, and practice resources
- Public interview experiences and preparation material
- Placement guidance that is useful, accurate, and okay to share
- Clear source links and credits for original creators

## What does not belong here

- Confidential assessment content, leaks, or anything shared against a company's rules
- Paid resources copied without permission
- Answer tools, cheating tools, or ways to bypass proctoring
- Personal information that someone did not choose to make public

## Adding material

1. Place company-specific material in its matching company folder at the repository root.
2. Create a company folder when the resource is company-specific and one does not exist.
3. Put general interview or placement material in `Other Resources`.
4. If a useful public repository already hosts the material, prefer linking it in [`Additional Resources`](<Additional Resources/README.md>) instead of copying files with unclear redistribution rights.
5. Include a short note with the source, date if known, and what the material covers.
6. Add it to [INDEX.md](INDEX.md).
7. Add your name or handle if you would like credit.

## Tiny quality check

Before sending a pull request, ask: would this help a stressed student in a real way? If yes, you are probably cooking. 🍳
