## How to add an entry

1. Put company-specific material in the matching root-level company folder. Put general material in `Other Resources`.
2. Add one row here with a clear link and the original public source.
3. Credit the contributor if they want to be named.

Clean index, calm brain. We love a searchable repo. ✨

If you recognise an original source in the imported archive, please open an issue or send a pull request so it can be credited properly.

Four files are temporarily parked outside the push in [`problem files`](problem%20files/RECOVERY-MAP.md) because Windows Git could not index their original filenames.
