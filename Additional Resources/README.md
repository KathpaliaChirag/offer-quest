## Why links instead of copied PDFs?

Some public repos contain mixed-source PDFs, personal notes, or unclear redistribution terms. Offer Quest keeps attribution clean and avoids silently mirroring material that an author may not have licensed for redistribution. If a creator confirms that a file can be mirrored, open an issue with the permission and we can add it to the matching company folder.

## Deep-research additions

Checked on 31 August 2026. These are strong complements to the local archive, especially when you need recent company coverage, frequency filters, mock tests, or a missing PDF.

### More company-wise question sources

- [MysteryVaibhav/leetcode_company_wise_questions](https://github.com/MysteryVaibhav/leetcode_company_wise_questions) - PDF-indexed company-wise LeetCode question lists. Treat these as interview/OA practice references, not leaked live tests.
- [Kali-Prem/leetcode-company-wise-interview-questions](https://github.com/Kali-Prem/leetcode-company-wise-interview-questions) - frequency-oriented CSVs plus 7-day, 30-day, and 90-day study plans.

- [cu-sanjay/Flipkart-GRiD-8.0-2026](https://github.com/cu-sanjay/Flipkart-GRiD-8.0-2026) - Flipkart GRiD previous-year programming round material.
