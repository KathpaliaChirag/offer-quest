# Texas Instruments - community OA recollection

Community submission, shared 28 August 2026.

This is a first-hand recollection, not an official TI question bank. The contributor could not photograph the supervised lab test.

- DSA was described as easy string manipulation. One example used a card-deck style input where each draw adds or subtracts one and the final total is returned.
- Another problem built every prefix of an integer string, summed the prefix values, reversed the resulting value, and returned it.
- MCQs reportedly covered computer networks, MAC addresses, ARP, SQL result-selection queries, aptitude, graphs, seating arrangements, and basic computer architecture.
- The contributor reported a HirePro driver-code issue affecting some C++ submissions. Check the generated driver code carefully and test locally before submitting. Python submissions were reported as unaffected by that issue.

Use this as preparation guidance only. Test platforms and question sets can change.
